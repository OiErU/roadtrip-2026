# Forests & Waterfalls 2026

Phone guide for the 20–29 November 2026 roadtrip: Óbidos → Galicia (Camping As Nevedas) → Peneda-Gerês (Lamas de Mouro) → Óbidos.

Open in Safari → Share → Add to Home Screen.

- `data.js`: the trip itself (days, walks, checklists, places). Edit this to change the plan.
- `app.js`: renders the pages, live weather (Open-Meteo), and the map (Leaflet + OpenTopoMap).
- `img/`: photos, mostly from Wikimedia Commons (credits on the Info tab).
- `sw.js`: offline support. Bump `CACHE` when you change files.
